# WWWAPAS

## Pagina para empresa de marketing digital

Esta pagina es para una empresa de Marketing digital que desea establecer presencia en la web mostrando sus servicios y sus productos.

Para lograrlo, elabore una interfaz siguiendo un diseño establecido previamente para que la página muestre los
servicios y ventajas de trabajar con esta empresa de Marketing digital y no otra.

## Stack tecnológico

- FrontEnd: HTML y CSS.
- Herramientas: Visual Studio Code, Asistencia de IA Claude, Git, GitHub.

## Demo

[Demo](https://mchuquimia.github.io/wwwapas/)

Este proyecto fue desarrollado con foco en la versión desktop.
La adaptación responsive (mobile) está pendiente como mejora futura.
